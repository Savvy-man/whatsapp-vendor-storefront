# WhatsApp-Integrated Vendor Storefront

A mobile-first e-commerce storefront built with React, Node.js, Express, and MongoDB that formats customer orders and neighborhood delivery fees into ready-to-send WhatsApp messages.

## Features
- Mobile-first product catalog with category filtering
- Dynamic neighborhood delivery fee calculator
- One-tap WhatsApp order summary generator
- PIN-protected Vendor Admin Panel for adding items and toggling stock status

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express, MongoDB (Mongoose)
